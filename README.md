# Escape-Archive
Escape Archive
Seungjae의 웹탈출 게임 포트폴리오. HTML, CSS, JavaScript로 구성된 정적 사이트입니다.
포함된 작품
졸업하지 못한 아이 — 업그레이드 2.0
새벽 2시 17분 — 업그레이드 2.0
포트폴리오에는 작품 소개, 장르별 목록, 브라우저 플레이, 미리보기 ZIP 다운로드가 있습니다. 현재 작품은 미리보기 상태로 표시됩니다. 사이트 공개 범위는 Sites에서 관리하며, 이번 버전은 소유자만 접근할 수 있게 게시합니다.
새 작품 추가
게임의 HTML, CSS, JS, 이미지를 `dist/games/<새로운-id>/` 폴더에 넣습니다. 게임 시작 파일은 보통 `index.html`입니다.
미리보기 ZIP이 있다면 `dist/downloads/`에 넣습니다.
`dist/projects.js`의 `projects` 배열에 기존 항목을 복사해서 제목, 고유 id, 설명, 이미지, 경로를 입력합니다.
`number`는 작품 번호, `status`는 `preview`(미리보기), `released`(플레이 가능), `draft`(제작 중)입니다. 제작 중인 항목은 플레이 버튼을 표시하지 않습니다.
이미지와 게임 경로는 `./games/...`, 다운로드 경로는 `./downloads/...` 형식의 상대 경로를 사용합니다. `..` 경로는 허용하지 않습니다.
변경 사항을 저장하고 사이트의 새 버전을 게시하면 작품 목록과 소개 화면에 자동으로 반영됩니다.
현재 사이트는 작품 파일을 편집해 등록하는 구조이며, 브라우저 내 관리·업로드 화면은 포함하지 않습니다. 향후 대화에서 게임 파일과 소개를 전달하면 같은 포트폴리오의 목록에 이어서 추가할 수 있습니다.
`id`를 바꾸지 않으면 해당 작품의 주소가 유지됩니다. 배열 순서가 목록 순서이며, 현재는 최근 작업이 위에 있습니다. 새로운 장르가 필요하면 `index.html`의 필터 버튼에도 동일한 category 값을 추가합니다.
로컬 실행
`dist/index.html`을 브라우저에서 열면 됩니다. 모듈이나 네트워크 요청 없이 로컬 파일로도 동작합니다. 작품 플레이 주소는 `play.html?id=...`, 소개 주소는 `project.html?id=...`입니다.
게임 진행은 각 게임의 브라우저 저장소를 사용합니다. 이전 ZIP에서 플레이한 진행은 게임의 진행 파일 내보내기·불러오기 기능으로 옮길 수 있습니다. 내장 플레이와 새 창 플레이는 같은 사이트의 게임 경로를 사용합니다.
콘텐츠 관리 원칙
기존 게임의 제목, 이야기와 저장 키를 보존했습니다.
게임들은 포트폴리오에 복사된 미리보기 스냅샷입니다. 원래 프로젝트를 수정했다면 이 스냅샷과 ZIP도 함께 갱신해야 합니다.
다운로드 파일에는 원본 게임의 실행 방법과 변경 내역이 들어 있습니다.
이름과 사과문 등 게임 진행 기록은 게임 로컬 저장소에만 저장됩니다. 포트폴리오는 별도의 서버 수집 기능을 사용하지 않습니다.
