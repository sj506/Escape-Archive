# Escape Archive

Seungjae의 웹탈출 게임 포트폴리오. HTML, CSS, JavaScript로 구성된 정적 사이트입니다.

## 포함된 작품

- 바람이 쉬어 가는 우체국 — 1.1, 난이도 상의 힐링 추리
- 졸업하지 못한 아이 — 업그레이드 2.0
- 새벽 2시 17분 — 업그레이드 2.0

포트폴리오에는 작품 소개, 장르별 목록, 브라우저 플레이, 미리보기 ZIP 다운로드가 있습니다. 현재 작품은 미리보기 상태로 표시됩니다. 이 저장소는 최상위 폴더의 index.html을 시작 페이지로 사용합니다.

## 새 작품 추가

1. 게임의 HTML, CSS, JS, 이미지를 `games/<새로운-id>/` 폴더에 넣습니다. 게임 시작 파일은 보통 `index.html`입니다.
2. 미리보기 ZIP이 있다면 `downloads/`에 넣습니다.
3. `projects.js`의 `projects` 배열에 기존 항목을 복사해서 제목, 고유 id, 설명, 이미지, 경로를 입력합니다.
4. `number`는 작품 번호, `status`는 `preview`(미리보기), `released`(플레이 가능), `draft`(제작 중)입니다. 제작 중인 항목은 플레이 버튼을 표시하지 않습니다.
5. 이미지와 게임 경로는 `./games/...`, 다운로드 경로는 `./downloads/...` 형식의 상대 경로를 사용합니다. `..` 경로는 허용하지 않습니다.
6. 변경 사항을 저장하고 사이트의 새 버전을 게시하면 작품 목록과 소개 화면에 자동으로 반영됩니다.

현재 사이트는 작품 파일을 편집해 등록하는 구조이며, 브라우저 내 관리·업로드 화면은 포함하지 않습니다. 향후 대화에서 게임 파일과 소개를 전달하면 같은 포트폴리오의 목록에 이어서 추가할 수 있습니다.

`id`를 바꾸지 않으면 해당 작품의 주소가 유지됩니다. 배열 순서가 목록 순서이며, 현재는 최근 작업이 위에 있습니다. 새로운 장르가 필요하면 `index.html`의 필터 버튼에도 동일한 category 값을 추가합니다.

## 로컬 실행

`index.html`을 브라우저에서 열면 됩니다. 모듈이나 네트워크 요청 없이 로컬 파일로도 동작합니다. 작품 플레이 주소는 `play.html?id=...`, 소개 주소는 `project.html?id=...`입니다.

게임 진행은 각 게임의 브라우저 저장소를 사용합니다. 이전 ZIP에서 플레이한 진행은 게임의 진행 파일 내보내기·불러오기 기능으로 옮길 수 있습니다. 내장 플레이와 새 창 플레이는 같은 사이트의 게임 경로를 사용합니다.

## 콘텐츠 관리 원칙

- 기존 게임의 제목, 이야기와 저장 키를 보존했습니다.
- 게임들은 포트폴리오에 복사된 미리보기 스냅샷입니다. 원래 프로젝트를 수정했다면 이 스냅샷과 ZIP도 함께 갱신해야 합니다.
- 다운로드 파일에는 원본 게임의 실행 방법과 변경 내역이 들어 있습니다.
- 이름과 사과문 등 게임 진행 기록은 게임 로컬 저장소에만 저장됩니다. 포트폴리오는 별도의 서버 수집 기능을 사용하지 않습니다.

## 배경음악

포트폴리오에는 「기록의 입구」, 학교 게임에는 「빈 교실의 약속」, 실종 게임에는 「02:17 · 남겨진 신호」가 포함됩니다. 우체국 게임에는 잔잔한 현악기풍 연주와 바다를 닮은 소리가 들어 있습니다. 외부 음원 없이 Web Audio로 생성하는 오리지널 음악이며 인터넷 없이도 동작합니다.

포트폴리오는 음악 켜기를 눌러 시작하고, 게임은 시작 버튼을 누르면 해당 테마를 재생합니다. 우측 하단에서 끄거나 음량을 바꿀 수 있고, 게임별 음량과 끄기 설정은 이 브라우저에 보관됩니다. 탭을 벗어나면 음악을 멈추며 돌아온 뒤 음악 켜기를 눌러 재개합니다. 브라우저가 재생을 제한하면 음악 켜기 버튼으로 시작하세요. 포트폴리오에서 게임으로 이동할 때 배경음은 멈춥니다.

우체국 게임의 음악 버튼은 상단에 있으며, 설정에서 음량을 바꿀 수 있습니다. 시작 이야기를 읽은 뒤 음악 사용 여부를 선택합니다.

음악 수정: 포트폴리오와 기존 두 게임은 각 폴더의 music.js 안 scores에 음계(MIDI 번호), 화음, 구간 길이가 있습니다. 우체국 게임은 별도의 music.js 안 chords와 연주 패턴을 사용합니다. 모든 게임과 다운로드 ZIP은 독립 실행됩니다.

## 바람이 쉬어 가는 우체국

`games/wind-post-office/index.html`에서 실행하거나 `play.html?id=wind-post-office`로 포트폴리오 안에서 플레이합니다. 소개는 `project.html?id=wind-post-office`입니다.

시작 시 마을 도착, 우체국장의 부탁, 조사·배달 방법을 세 장면 팝업으로 보여 줍니다. 다섯 퍼즐, 기록 18건, 조사 수첩과 단서 연결, 단계별 힌트, 저장 및 진행 파일 내보내기·불러오기를 제공합니다. 처음 이야기는 집배원 안내서에서 다시 읽을 수 있습니다.

다운로드 ZIP에는 전체 코드, 원본 그림, 실행 안내서, 정답을 포함한 제작 메모, 검증 스크립트가 들어 있습니다. 퍼즐·진행·저장과 시작 팝업에 관한 39개 검증 묶음을 통과했습니다. 실제 브라우저의 화면·소리 검수는 수행하지 않았습니다.

## GitHub Pages
